  1. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

Long format data refers to multiple rows for each observational unit (e.g. recurring ID numbers for test scores such as math/reading)–this is generally the preferred format for statistical analysis because it is expected by many R functions from visualization libraries (ggplot2) to statistical modeling functions (lm/ANOVA/mixed effects models).

Wide format data generally has one row for each observational unit with different measurements separated by columns (e.g. one ID number followed by a math column and a reading column).
