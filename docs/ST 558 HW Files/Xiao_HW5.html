3. Now write a quick function that allows the user to easily query this API. The inputs to the function should be the title/subject to search for (string), a time period to search from (string - you’ll search from that time until the present), and an API key.

#Query NewsAPI and return the article data frame
query_news <- function(subject, from_date, api_key) {

  response <- GET(
    url = "https://newsapi.org/v2/everything",
    query = list(
      q = subject,
      from = from_date,
      language = "en",
      pageSize = 50,
      apiKey = api_key
    )
  )
  #Parse JSON response
  parsed_response <- content(
    response,
    as = "parsed",
    simplifyVector = TRUE
  )
  as_tibble(parsed_response$articles)
}
